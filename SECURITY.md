# Sikkerhet

Ikke legg sikkerhetshull eller hemmeligheter i offentlige issues. Kontakt prosjekteieren privat ved en alvorlig sårbarhet.

Prosjekter som bruker rammeverket skal:

- validere data både i klient og server når en server finnes
- bruke minst mulige tilganger
- holde private data utenfor logger og GitHub
- rotere en hemmelighet umiddelbart dersom den ved et uhell blir eksponert
- dokumentere hvilke data som lagres og hvordan de kan slettes

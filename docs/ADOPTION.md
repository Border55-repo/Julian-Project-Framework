# Innføring i eksisterende prosjekter

1. Kartlegg plattform, byggkommando, testkommando, lagring og deploy.
2. Opprett branchen `chore/adopt-julian-framework`.
3. Legg inn `.editorconfig`, `SECURITY.md`, prosjektstandard og pull request-mal.
4. Tilpass CI til prosjektets faktiske kommandoer. Ikke kopier en workflow ukritisk.
5. Kjør tester og bygging lokalt.
6. Opprett en pull request som beskriver nøyaktig hvilke kontroller som er innført.
7. Slå sammen først når CI er grønn.

Eksisterende appkode skal ikke omskrives bare for å passe rammeverket. Innføringen skal være liten, reverserbar og teknologitilpasset.
